# The Leafcroft charter

Leafcroft is a free, open-source notes platform. Your notes are plain files on your own device. A small core app reads them, and plugins, themes and starter kits do the rest. This page is the promise behind the word "free", and what holds that promise in place.

## What we promise

1. You never pay. There is no paid tier, no paid sync, no paid plugin from us, and no "free for personal use". If a feature exists, everyone has it.

2. Your notes stay plain files. They open in any text editor today and will open in any text editor in twenty years. Nothing we build makes them depend on us.

3. The folder format is public. The spec and its test files are published under an open license, so anyone can build an app that reads and writes your notes. We will not change the format quietly, and we will not break files that already exist.

4. No ads, no tracking, no selling data. The app makes no network connection you did not ask for.

5. The license stays open. The code and the spec are released under licenses the Open Source Initiative approves. We will not relicense them. Code that is already out can never be taken back, and we will not try with the code that follows.

## How it is paid for

Donations and grants pay for people's time. There are no servers to run, so the cash costs are small. We publish them on a running cost sheet, so you can see where the money goes.

Money will be held by a nonprofit fiscal sponsor, not by a company. We plan to apply to Open Source Collective as soon as the project meets its requirements. Until it is accepted, Jordan Krueger holds the accounts personally and every dollar appears on the cost sheet.

There are no investors, and there is no company to sell.

## Who decides

Maintainers are listed in the repository. Within the first months, at least two people hold owner access to the code, the domains and the plugin directory. No single person can lose or lock the project.

Changes to the folder format or the plugin interface go through written proposals, in public, before they land. Ordinary fixes are ordinary pull requests.

Plugins are made by anyone. Being listed in the directory is not an endorsement. Every plugin says what it touches before you install it, and authors choose their own licenses.

## If we stop

If every maintainer walks away, your notes still work. They are files. The code and the spec stay under their licenses, and anyone may fork and continue. The domains and the GitHub organization pass to the fiscal sponsor, or to a successor named in the repository.

## Changing this charter

A change can strengthen a promise. It cannot weaken one. Any change is announced before it takes effect and is recorded in the repository history.
